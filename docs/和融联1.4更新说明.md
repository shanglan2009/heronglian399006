# 和融联1.4：持仓风控与运行健康

新增独立下跌风控，优先于原高抛低吸买入条件。原“风险条件满足数”更名“顶部过热条件数”，与下跌风险分开显示。

## 当前工程默认规则

|等级|条件（取最严重一级）|登记股票仓位上限|
|---|---|---|
|趋势转弱|当前价低于20日均线，前一个完整日也低于其此前20日均线，且20日均线向下|60%|
|破位防守|连续两个完整日分别低于其此前60日均线，当前仍未收复；或跌破此前20日最低价超过0.5倍ATR|35%|
|严重回撤|相对此前60日最高收盘回撤至少12%且低于60日均线；或登记账户观测峰值回撤至少12%|15%|
|账户回撤超限|登记账户观测峰值回撤至少20%|0%|

这些数值是可审计的初始保护参数，未证明收益最优。分母为登记持仓按ETF新鲜报价估值加登记现金，不把成本价当作资产峰值。首次启用从既有账户收盘记录和当前有效估值建立观测峰值，以后只在有效交易时段用新鲜行情更新。峰值是采样值，不是账户实际历史最高值；账外资金变化需人工核对。

风险需同一级别在有效行情中持续至少60秒确认；采样间隔超过120秒重新确认。只在交易时段、指数与ETF报价都新鲜且无数据错误时提醒。数据不足显示“无法判断”，不会当成零风险。期间禁止新买；已确认风险缓解后仍须原买点条件满足，不自动补仓。

每天对持续风险提醒一次，级别提高时可再次提醒。风险提醒不受普通机会去重及每日同向上限阻挡。减仓数量为按最新登记持仓重新计算至目标上限的参考数量，并受100份单位与T+1可卖份额约束；不是追加卖单。未登记实际成交时不会假定已经减仓。无可卖份额时仍提示风险，但不捏造可执行卖出量。

## 运行健康

新增每交易日首次/最后轮询、有效行情采样次数与间隔缺口记录。交易时段同一时段内轮询间隔超过3分钟会记录缺口，午休不计入。

检测到行情失效、09:40后没有有效开盘判断、15:15后没有收盘复盘、以及启用新版后上一交易日缺少复盘时，按日去重发出健康提醒。断网/退出/关机期间程序不能实时通知，只能恢复后发现部分缺口。采样次数不能证明全天连续运行。

新增数据库表和设置采用只增不覆盖迁移；持仓、现金、实际成交、旧决策、加密令牌、自启配置均保留。旧程序和数据库在部署前备份。个股实验室不变。
